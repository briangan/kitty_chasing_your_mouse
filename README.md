# About

A simple Mac utility to add an animated 2D icon of a kitty following the mouse pointer.  The actions of the kitty would be
* Run & catch the moving mouse pointer with running animation
* When the kitty catches the mouse pointer, bite it and hold in mouth for 3 seconds and the kitty starts sitting and waiting.
* When the kitty is in eating or waiting or sleeping position, click on the kitty fades it away.
* When the kitty is waiting, scrub and pet the kitty to howl joyfully upwards slightly by swinging the mouse left and right 3 times.
* When the mouse pointer is idle for a minute or more, the kitty takes a nap next to it.

Because my knowledge of Swift framework for Mac application is only at beginner level, I'm only using AI to generate at start.  The first version of the app was generated by Claude Code Sonnet 5.5.  The initially generated codes are written in some primitive style with static methods at main level instead of being defined in class such as main App.  It needs its own build script to compile the codes into .app package.  Otherwise, the use of XCode creates an app with neccary structure for IDE to run project functions.

# Usage

This is an experimental utility for fun, so you are free to [download for personal use](KittyChasingYourMouse.app).  I have not re-registered myself as Apple developer program yet, so you'd need to approve yourself by clicking Open (see popup message below by Mac OS), and drop into /Applications folders.
```
"KittyChasingYourMouse.app" is an app downloaded from the internet.  
Are you sure you want to open it?
```

After launch, a kitty icon will appear at top in your control panel icons area.  That has the menu command to Quit.  And it has command to Call the Kitty too.  [See Menu](images/menu.png)
